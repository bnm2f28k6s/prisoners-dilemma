# The levels

Follow the [walkthrough and level map](/) in order, starting with [Level 0: one simultaneous choice](/levels/00-one-shot). Each lesson links to the next. The numbered sidebar follows the same sequence.

At every step, ask what changed, what stayed fixed, and how the earlier model can be recovered. Each lesson's **Build this version** section gives implementation changes, language-neutral pseudocode, and concrete checks. The [build-along guide](/build-along) introduces the shared notation and workflow. Earlier mechanisms remain available even when a worked example turns them off to isolate a new one.

After Level 18, continue to the [combined model](/conceptual-model), which gathers the settings and helps you connect and verify the pieces you built.
